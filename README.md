# All-in Randomizer

A modular, customizable randomization toolkit.

## Planned Features

- Dice roller
- Coin flipper
- Number generator
- Item picker
- Hex color generator
- More randomizers as the project grows

## Technology

- Python
- Git

## Setup

Create and activate a virtual environment, then install
the project:

    python -m venv .venv
    python -m pip install -e .

## Run

    python -m all-in_randomizer.main

## Tests

    python -m unittest discover -s tests
